# Memory Lab

Begleitprojekt zum Blogpost „Memory ist kein Feature, sondern Datenarchitektur“ auf rubeen.dev: ein Bücherei-Assistent mit zwei Memory-Architekturen (ein Topf vs. getrennte Stores), gemessen an sechs Szenarien. Spezifikation: [docs/spec.md](docs/spec.md).

Im Aufbau. Engine (`src/engine/`) übernommen aus [grader-lab](https://github.com/rubenvitt/grader-lab).
